# Operator Interaction Layer And Foundation

`OperatorInteractionLayer` is now projected from a shared server-side factory instead of being assembled inside the frame builder. The foundation projector is a typed factory over shell family, so later portal and governance work can reuse the same schema-backed semantics without copying constant tables into route code.

## Calm-Shell Foundation

For `CALM_SHELL`, `projectInteractionLayerFoundationContract` emits the frozen interaction foundation: four-surface density and spacing, detail-drawer support spacing, support redock compaction, operator semantic selectors, same-object same-shell inline recovery, inline explicit rebase recovery, current-primary history posture, detail-drawer or parent-bound secondary-window preview, context-bound inline feedback with parent mirror, parent-bound support windows, subtle causal motion, and durable receipt or typed-failure feedback truth.

## Operator Layer

`projectOperatorInteractionLayer` derives the operator contract from that grouped foundation. The layer keeps mounted content, presents refresh inline, coalesces deltas before promotion, preserves summary-first investigation modules, keeps support windows parent-bound, and publishes `FAIL_CLOSED_DURING_DEGRADED_OR_RECOVERY` so renderers cannot keep unsafe mutations visually live through stale, degraded, recovery, or no-safe-action posture.

## Embodiment Posture

Browser and primary native calm-shell frames use `recovery_notice_surface = CONTEXT_BAR`, `notification_surface = CONTEXT_BAR`, and `artifact_preview_surface = DETAIL_DRAWER`.

`IDENTITY_HEADER` is lawful only for parent-bound support windows or detached support scenes. Those support embodiments also publish `notification_surface = PARENT_CONTEXT_BAR` and `artifact_preview_surface = SECONDARY_WINDOW_BODY`; they remain support-only and close back to the parent focus context.

System notification mirrors may use `CONTEXT_BAR_WITH_SYSTEM_MIRROR`, but the owning calm shell remains the source of settlement, recovery, and current-versus-history truth.

## Frame Integration

`buildLowNoiseExperienceFrame` now calls `projectOperatorInteractionLayer`, and `validateLowNoiseFramePublication` reprojects the expected interaction layer before publication. Any drift in foundation tokens, preview surface, notification surface, history posture, recovery notice placement, continuity policy, motion profile, or unsafe-action policy is rejected server-side.
